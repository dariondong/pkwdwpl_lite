PKWDWPL Lite — 离线地图底图目录
================================

把一张地图图片（PNG）命名为 `offline_map.png` 放在本目录，
App 的「离线地图」页就会自动把它当底图（不需要改代码）。

要求 / 说明：
1. 图片会被拉伸到「经纬范围」对应的画布上，所以请确保**图片的地理范围**和
   App 里设置的 / 自动推导的范围一致，否则点位会偏。
2. 范围来源优先级：
   a. 连接页 → 设置 → 「地图经纬范围」里手填（minLat/maxLat/minLon/maxLon）；
   b. 没填时按「收到的全部台站 + 本机参考坐标」自动生成。
   想固定用某张地图，推荐用 a 手动锁定范围。
3. 投影方式：等距圆柱（equirectangular），局部小范围内误差可忽略；
   经纬网线按 6~12 条自适应。
4. 不建议放太大（> 4K）的图片：会明显增加内存占用；建议 2000×2000 左右。
5. 本文件只是占位说明，删掉不影响构建。

不用底图也能用：
没有 `offline_map.png` 时，地图页会绘制经纬网格 + 全部台站点位 + 比例尺，
双击列表项照样能「居中」查看该台站与其它台站的相对位置，
而且完全离线、不需要 GPS。
